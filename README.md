# 棋淵 Abyss Gambit

一個「每張牌都是一種棋步」的回合制 roguelike 解謎遊戲。純 HTML / CSS / JavaScript，不需要安裝或建置。

**▶ 立即遊玩：https://abvesa.github.io/abyss_gambit/**（電腦、手機瀏覽器都可以；iPhone 可用 Safari「加入主畫面」全螢幕遊玩）

## 怎麼玩

打開上面的連結，或直接用瀏覽器打開本機的 `index.html`。進度存在各自瀏覽器的 localStorage，手機和電腦的進度不互通。

手機操作：點牌 → 點落點預覽 → 再點一次確認；點敵人看它的行為，長按牌或技能看說明。

核心規則：

- 每回合抽 3 張牌，每張是一種走法（王、騎、車、象、后……），走到敵人身上就是攻擊。
- **擊殺就能再出一張牌**（連鎖）；沒殺到，回合就結束。「迅捷」牌不會結束回合。
- 敵人的攻擊會提前一回合用紅格標示，而且會打到自己人：借刀殺人、推落深淵。
- 每回合至少要出一張牌；超過標準回合數後地面開始崩塌。
- 第 5、10 層有首領。另有每日挑戰（同一天大家同一個種子）與 3 個可解鎖角色。

### 兩種模式

- **故事模式**：選一位英雄挑戰十層棋淵。
- **無盡之塔**：在「命盤」用點數自訂角色（生命、回溯、手牌上限、主動技能、起始遺物、起始牌組、起點），看構築能爬多高。
  - 每層之前**選門**：平穩 / 險峻 / 深淵之門，越險魂晶越多、獎勵越好。
  - 越往上，敵人會帶**詞條**（護盾、厚皮、狂暴、疾行、爆裂、荊棘、再生、分裂、不動、幽影），樓層會有**干擾**（灼地、大軍、精銳、崩落、疾風、暗影、詛咒）或祝福（靈泉、魔力潮）。
  - 每次攀登（故事模式也算）帶回**魂晶**，到**魂晶工坊**解鎖新的牌、技能、遺物、更多構築點數，或從更高層出發（出發前先挑幾次補給）。

快捷鍵：`1`–`4` 選牌、`Q` `W` 技能、`空白` 結束回合、`Z` 回溯、`Esc` 取消。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `engine.js` | 遊戲規則與敵人 AI（純邏輯、可決定性亂數，不碰 DOM） |
| `ui.js` | 繪製、輸入、動畫、音效（WebAudio 合成）、存檔 |
| `style.css` | 版面與視覺 |
| `tests/sim.js` | 用機器人自動玩上百局，檢查不變量並估算難度 |

## 測試 / 平衡

```bash
node tests/sim.js 60 15         # 故事模式：隨機機器人 + 貪婪機器人，最多玩到第 15 層
node tests/sim.js 15 60 tower   # 無盡之塔：基本構築與強力構築各爬幾次
```

改完 CSS / JS 要上線時，記得把 `index.html` 裡 `?v=6` 的數字加一，手機（尤其是加到主畫面的版本）才不會一直用舊的快取。

想調難度，主要旋鈕都在 `engine.js`：

- `startFloor` 裡的 `budget`（每層敵人數量）與 `S.par`（標準回合數）
- `maxActive`（同時在場的敵人上限）
- `spawnEnemy` 裡的精英機率
- `ENEMIES` / `CARDS` / `RELICS` / `SKILLS` / `AFFIXES` / `MODS` 資料表（新增內容從這裡開始）
- 無盡之塔：`towerScale`（血量 / 傷害成長）、`rollAffixes`（詞條機率）、`genDoors`（門的設計）、`TOWER`（點數規則與工坊價格）

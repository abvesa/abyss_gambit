# 棋淵 Abyss Gambit

一個「先走一步、再出一招」的棋步卡牌 roguelike 解謎遊戲。純 HTML / CSS / JavaScript，不需要安裝或建置。

**▶ 立即遊玩：https://abvesa.github.io/abyss_gambit/**（電腦、手機瀏覽器都可以；iPhone 可用 Safari「加入主畫面」全螢幕遊玩）

## 怎麼玩

打開上面的連結，或直接用瀏覽器打開本機的 `index.html`。進度存在各自瀏覽器的 localStorage，手機和電腦的進度不互通。

手機操作：點牌 → 點落點預覽 → 再點一次確認；點敵人看它的行為，長按牌或技能看說明。

核心規則：

- 每回合抽 4 張牌。牌分兩種：**步**是棋步（王、騎、車、象、后……），走到敵人身上就是攻擊；**技**是原地出招（橫斬、長槍、弩箭、架式、鉤鎖……）。
- 每回合可以出一張步、一張技，**出招之後就不能再走**。
- **擊殺換來一次額外行動**（步或技都可以），連鎖下去。「迅捷」牌不佔用行動。
- 近身攻擊（走到敵人身上、橫斬、迴旋、斷首、落地衝擊）會被刺蝟和「荊棘」刺傷；「結界」敵人只吃近身攻擊。牌組裡兩種都要有。
- 敵人的攻擊會提前一回合用紅格標示，而且會打到自己人：借刀殺人、推落深淵。
- 每回合至少要出一張牌；超過標準回合數後地面開始崩塌。
- 第 5、10 層有首領。另有每日挑戰（同一天大家同一個種子）與 3 個可解鎖角色。

### 兩種模式

- **故事模式**：選一位英雄挑戰十層棋淵。
- **無盡之塔**：在「命盤」用點數自訂角色（生命、回溯、手牌上限、主動技能、起始遺物、起始牌組、起點），看構築能爬多高。
  - 每層之前**選門**：平穩 / 險峻 / 深淵之門，越險魂晶越多、獎勵越好。每道門還附一個**懸賞**（連斬、借刀、推落、武藝、吃子、無傷），達成後魂晶 ×1.5、獎勵多一個選項。
  - **遺物最多 6 件、生命上限最多 12**：拿第 7 件遺物要換掉一件，每一局都得決定要走哪個流派（連鎖、推落、槍陣、借刀、鐵壁、躍擊……）。
  - 越往上，敵人會帶**詞條**（護盾、厚皮、狂暴、疾行、爆裂、荊棘、再生、分裂、不動、幽影、結界），敵人越來越多、場上越來越擠，樓層會有**干擾**（灼地、大軍、精銳、崩落、疾風、暗影、詛咒）或祝福（靈泉、魔力潮）。
  - 每次攀登（故事模式也算）帶回**魂晶**，到**魂晶工坊**解鎖新的牌、技能、遺物、更多構築點數，或從更高層出發（出發前先挑幾次補給）。

快捷鍵：`1`–`5` 選牌、`Q` `W` 技能、`空白` 結束回合、`Z` 回溯、`Esc` 取消。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `engine.js` | 遊戲規則與敵人 AI（純邏輯、可決定性亂數，不碰 DOM） |
| `ui.js` | 繪製、輸入、動畫、音效（WebAudio 合成）、存檔 |
| `style.css` | 版面與視覺 |
| `tests/sim.js` | 用機器人自動玩上百局，檢查不變量並估算難度 |

## 測試 / 平衡

```bash
node tests/sim.js 60 15         # 故事模式：隨機機器人 + 貪婪機器人，最多玩到第 15 層
node tests/sim.js 15 60 tower          # 無盡之塔：每個流派的構築各爬幾次（從第 1 層出發）
node tests/sim.js 30 60 tower push     # 只跑某個流派（逗號分隔）
DIAG=1 node tests/sim.js 15 60 tower   # 另外統計玩家的傷害來源
```

改完 CSS / JS 要上線時，記得把 `index.html` 裡 `?v=6` 的數字加一，手機（尤其是加到主畫面的版本）才不會一直用舊的快取。

想調難度，主要旋鈕都在 `engine.js`：

- `startFloor` 裡的 `budget`（每層敵人數量）與 `S.par`（標準回合數）
- `maxActive`（同時在場的敵人上限）
- `spawnEnemy` 裡的精英機率
- `ENEMIES` / `CARDS` / `RELICS` / `SKILLS` / `AFFIXES` / `MODS` 資料表（新增內容從這裡開始）
- 無盡之塔：`towerScale`（血量 / 傷害成長）、`maxActive` 與 `startFloor` 的 `fe`（高樓層的敵人密度）、`rollAffixes`（詞條機率）、`genDoors`（門與懸賞）、`TASKS`（懸賞）、`TOWER`（點數規則與工坊價格）
- 上限：`RELIC_CAP`（遺物欄位）、`HP_CAP`（生命上限）、`minDeck`（牌組最少張數）
